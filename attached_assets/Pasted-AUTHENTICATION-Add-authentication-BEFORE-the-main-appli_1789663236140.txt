==================================================
SENSOR SYNCHRONIZATION

Accelerometer and gyroscope produce separate streams.

Synchronize using timestamps/latest readings.

Do not blindly assume that the nth accelerometer event equals
the nth gyroscope event.

Create:

SensorSample:

{
ax,
ay,
az,
gx,
gy,
gz,
timestamp
}

==================================================
SLIDING WINDOW

WINDOW_SIZE = 150

STRIDE = 15

Maintain an in-memory buffer.

When:

buffer.length >= 150

create:

150 × 6 window.

Example:

[
[ax, ay, az, gx, gy, gz],
[ax, ay, az, gx, gy, gz],
...
]

Send the complete window to the inference service.

After processing:

remove first 15 samples.

Window 1:

1–150

Window 2:

16–165

Window 3:

31–180

Never send individual sensor readings to the backend.

AWS PREDICTION API

API Gateway:

POST /predict

Lambda:

predictionLambda

Responsibilities:

Validate authenticated user.
Validate sessionId.
Validate sensor window.
Ensure window contains 150 rows.
Ensure every row contains 6 values.
Run the configured inference model.
Return status and confidence.
Log prediction event.

Response:

{
"status": "SAFE | ALERT | EMERGENCY",
"confidence": 0.0
}

the mock logic later.
